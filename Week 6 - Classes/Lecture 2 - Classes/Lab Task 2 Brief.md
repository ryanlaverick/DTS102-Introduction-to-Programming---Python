# Task 2
## Class definition
Create a class to store information about books. That class should have the following
methods:
- Created different methods with appropriate names to add for each book the
following information:
  - Title, author, published year and random number generated for ISBN
- Create different methods with appropriate names to update the following
  information about a book
  o Title, author and publication year
  
## Constructor
Write a constructor for the class so that it takes the following information as arguments:
- Book title, author, and publication year. 
  
## Object creation
  - Create at least three instances of your class.
  - Use the instances you have just created to update the information stored in the
  objects for each book. For example, change the title of the book
  - Use the instance for each object to access the attributes of the book. See slide
  number 16 from the lecture.
